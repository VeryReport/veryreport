## 值班规则

1. **响应 SLA：** 工作日问题尽量 **48 小时内**首响（可先致谢 + 预计时间）。  
2. **事实核对：** 涉能力边界的回答须对照官网产品页 / 帮助文档；不确定则转销售/实施，不编造。  
3. **转化：** 试用 / 报价类引导至带 UTM 的官网链接（见 `link-utm.md`，`utm_medium=discussion`）。  
4. **回写：** 优质问答整理进 `FAQ.md`（实现阶段）。  
5. **禁止：** 承诺未交付功能、提供未公开 API/SDK、假装本仓可编译产品。
