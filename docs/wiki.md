# Wiki 说明

本仓优先用 **仓库内 Markdown**（`docs/`、`faq/`、`examples/`、`ai/`）作为可版本管理的「Wiki」内容，便于 PR 与 SEO 抓取。

若启用 GitHub Wiki，请仅作镜像或短链，**避免**两处长期不一致。推荐首页只放：

```text
Canonical docs live in the repository:
- docs/README.md
- faq/README.md
- examples/README.md
- ai/README.md
- ROADMAP.md
```

不要在 Wiki 发布安装包、许可证或 API Spec。
