# Contributing（边界说明）

Thank you for your interest. This repository is the **VeryReport Developer Hub** (marketing + developer docs), **not** an open-source application codebase.

## Accepted

- Documentation fixes (typos, broken links, clearer wording) via contact or Discussions after the repo enables them
- Example / FAQ topic suggestions (Ideas category)

## Not accepted

- Pull requests that assume product source lives here
- Requests for install packages, license keys, Docker images, or API/SDK dumps in Issues
- “Please open-source VeryReport” as a contribution path — product licensing is commercial ([pricing](https://www.veryreport.com/price?utm_source=github&utm_medium=docs&utm_campaign=developer_hub))

1. Read [`FAQ.md`](./FAQ.md) / [`faq/`](./faq/README.md) and [`examples/`](./examples/README.md)
