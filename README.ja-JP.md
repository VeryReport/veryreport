## VeryReport とは

VeryReport（中国語名：**非常报表**）は、中国企業でよくあるレポート／分析ニーズ向けに、**中国式の複雑レポート**、**セルフサービス BI**、**データ入力（填報）**、**ETL**、**データ大画面**、**Vera AI による自然言語分析**を一つのプラットフォームにまとめ、**SaaS サブスクリプション**と**オンプレミス（プライベート）導入**の両方に対応します。

多くの課題は「表が作れない」ことではなく、次のような点です。

- 財務／規制は正式レイアウト、現場はダッシュボード——指標の定義が一致しない  
- 表ができても、セル上で修正して業務 DB に書き戻したい  
- データは社内に置きたいが、まずは SaaS で価値検証したい  

VeryReport は、これらを複数ツールの継ぎ接ぎではなく、一つの製品として届けることを目指します。

```text
データソース ──▶ ETL / データセット ──▶ レポート · BI · 入力 · 大画面 · Vera AI
                                          │
                             SaaS トライアル / オンプレミス導入
```

| 項目 | 内容 |
|---|---|
| 製品カテゴリ | レポートツール + BI 分析ソフトウェア |
| コア機能 | 複雑レポート、セルフサービス BI、データ入力、ETL、データ大画面、Vera AI |
| 導入形態 | SaaS（ユーザー／年）· オンプレミス（同時接続、¥10,000 〜） |
| 開発元 | 中創微（上海）軟件有限公司 |

## VeryReport を選ぶ理由

- **中国式複雑レポートを第一級機能として**：グループ、クロス、パラメータ照会、帳票印刷、Word / Excel / PDF 出力  
- **レポートと分析が同じデータ基盤**：レポート指標と BI 指標のズレを減らす  
- **セル入力 + フォーム入力**：表上での訂正と、プロセス収集用フォーム  
- **SaaS とオンプレミスで機能同一**：まずトライアルで検証し、必要なら社内展開  
- **Vera AI**：自然言語での照会。プライベート／ローカル LLM に接続可能

## 向き・不向き

**向いている場合：**

- 中国式の正式レポートと経営分析の両方で、指標を揃えたい  
- 表のセル上で訂正／入力し、業務 DB に書き戻したい  
- まず SaaS で検証し、その後プライベート／社内（信創含む）へ展開したい  
- レポート・BI・大画面・入力を一つの製品で回したい  

**向いていない場合：**

- 個人で少量の CSV だけ分析する（デスクトップツールの方が軽い）  
- 本リポジトリを OSS エンジンとして二次開発したい（ソースは無い）  
- VeryReport を DWH 代わりの計算エンジンとみなす（クエリは下位 DB にプッシュダウン）

選定ガイド：https://www.veryreport.com/compare/report-tools
