## 适用场景

- 中国式表样、多级表头  
- 参数查询（日期区间）后导出 Excel / PDF  
- 可与 [格子填报](../../examples/mysql-fill/README.md) 扩展为订正表

## 表样要点

| 元素 | 说明 |
|------|------|
| 行维 | 大区 / 成本中心等 |
| 列维 | 产品线或月份 |
| 度量 | 金额合计、数量合计 |
| 参数 | `start_date` / `end_date` |
| 导出 | Word / Excel / PDF（以产品为准） |
