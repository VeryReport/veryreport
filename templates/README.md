# Templates

> **一句话定义：** Dashboard / Report / ETL 模板的**说明与预览入口**。  
> **边界（§14）：** ① **必须登录官网**后下载包体 ② 本仓**不**托管 `.vrpkg` 等二进制 ③ Star ≠ 获得模板文件。

## 如何获取

1. 阅读下方说明页（场景、适用模块、预览图）。  
2. 打开官网 [应用市场](https://www.veryreport.com/market?utm_source=github&utm_medium=template&utm_campaign=developer_hub) 或产品内模板入口。  
3. **登录账号**后下载；未登录无法获取包体。  
4. 无账号？先 [注册试用](https://www.veryreport.com/register?utm_source=github&utm_medium=template&utm_campaign=developer_hub)。
