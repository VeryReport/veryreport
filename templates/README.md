# Templates

> **一句话定义：** Dashboard / Report / ETL 模板的说明与预览入口。  
> **边界：** ① **必须登录官网后下载**包体（PRD §14） ② 本仓不托管 `.vrpkg` 等二进制 ③ Star 本仓不等于获得模板文件。

## 如何获取

1. 浏览下方说明（后续会补充预览图与适用场景）。  
2. 前往官网 [应用市场](https://www.veryreport.com/market?utm_source=github&utm_medium=template&utm_campaign=developer_hub) 或产品内模板入口。  
3. **登录账号**后下载；未登录无法获取包体。
