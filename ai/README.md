# Vera AI（Developer Hub）

> **一句话定义：** Vera 是 VeryReport 内置的 AI 数据智能体，覆盖问数、解读、报告、搭建等能力，与报表 / BI 数据同源。  
> **边界：** ① 下文仅写**已交付**能力 ② 不公开 API Spec / SDK ③ 操作细节以官网为准 ④ 规划中能力不写操作教程。

## 已支持

| 能力 | 说明 |
|------|------|
| 智能问数 | 自然语言提问 → 取数 / 图表；可展示分析过程与生成的 SQL |
| 智能解读 | 为已有图表生成叙事洞察 |
| 智能报告 | 多章节经营分析类输出 |
| 智能搭建 | 基于数据集一句话生成可编辑的仪表板初稿 |
| 过程可解释 | 分析链路可审计；SQL 可见、可修正后再执行 |
| 权限约束 | 基于数据集权限与行列级安全过滤（与人工查询同一套约束） |
| 私有化 / 本地大模型 | 可选企业大模型（如 DeepSeek 等），满足数据不出域诉求 |

## 不在本公开仓提供
