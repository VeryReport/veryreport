# FAQ · 产品与仓库

> 返回 [FAQ 索引](./README.md)

### VeryReport 开源吗？
不开源。本仓是 Developer Hub 宣传资料，不含产品源码。商业授权：SaaS / 私有化。

### 「非常报表」和 VeryReport 是什么关系？
同一产品。VeryReport 英文名，非常报表中文名。

### 本仓库能 git clone 后编译运行吗？
不能。请 [免费试用](https://www.veryreport.com/register?utm_source=github&utm_medium=faq&utm_campaign=developer_hub)。

### 本仓 `docs/` 和官网帮助文档有何区别？
官网 [https://www.veryreport.com/docs?utm_source=github&utm_medium=faq&utm_campaign=developer_hub](https://www.veryreport.com/docs?utm_source=github&utm_medium=faq&utm_campaign=developer_hub) 是操作手册；本仓 `docs/` 是开发者向架构 / 部署概述 / 集成概念，**不是**镜像复制。

### 接受 Pull Request / Issue 报 bug 吗？
不接受产品源码 PR。文档勘误与产品问题请走 [联系](https://www.veryreport.com/contact?utm_source=github&utm_medium=faq&utm_campaign=developer_hub) 或 [产品社区](https://www.veryreport.com/community?utm_source=github&utm_medium=faq&utm_campaign=developer_hub)。

### Star 本仓能拿到源码或安装包吗？
不能。Star 仅表示关注。

### 有社区版 / CE 吗？
公开材料中**不以**社区版开源引擎名义提供产品。请使用试用或商务采购。

### 公司主体是谁？
中创微（上海）软件有限公司。官网 [https://www.veryreport.com/?utm_source=github&utm_medium=faq&utm_campaign=developer_hub](https://www.veryreport.com/?utm_source=github&utm_medium=faq&utm_campaign=developer_hub)。

### 商标与 NOTICE 是什么？
见根目录 [`NOTICE`](../NOTICE)：宣传材料版权声明，**不是**开源许可证。

### Discussions / Issue 提问会被回复吗？
仓库启用 Discussions 后按周值班回复（见 `docs/discussions-duty.md`）；优质问答会回写 FAQ。产品缺陷请走商务/社区渠道。
